# Segurança e tratamento de dados

## Dados processados

O dashboard processa os arquivos selecionados localmente no navegador. Esta versão não possui chamadas de rede para upload de bases nem dependências externas de runtime.

## Regras de publicação

- Não faça commit de CSVs, TXTs, JSONs, XLS/XLSX ou PDFs com dados operacionais.
- Revise o histórico do Git antes de tornar o repositório público.
- Confirme as políticas internas de classificação, retenção e compartilhamento.
- Confirme a autorização de uso de marca e de publicação do código.
- Mantenha o GitHub Pages privado ou restrito quando a política da organização exigir.

## Relato de vulnerabilidade

Use o canal privado de segurança definido pela organização ou a funcionalidade **Private vulnerability reporting** do GitHub. Não publique exemplos que revelem dados reais.

Ao relatar, informe:

- versão/commit afetado;
- navegador e sistema;
- passos mínimos de reprodução;
- impacto esperado;
- evidência anonimizada.
